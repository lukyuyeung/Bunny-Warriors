# Bunny Warriors Exhibition

Static game exhibition with 68 searchable skills, skill details, three frost VFX videos and downloadable assets. Uses supplied concept art; concept previews and scripted demonstrations are labeled.

Run: `cd /workspace/Bunny-Warriors && npm start`. Validate JavaScript: `npm run check`.

No package installation, API keys or backend are required. Deploy the directory containing index.html, style.css, app.js and assets/ to a static web host. The site uses relative URLs and supports subdirectory hosting. Public hosting and a domain are not configured in this workspace.

Original handoff assets remain under /workspace/bunny-design. Do not treat image text as the current mechanics specification; skills_all.json supplies displayed mechanics. The site does not implement playable combat, accounts, currencies or gacha.
